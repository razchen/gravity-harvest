Which buildings each release needs. The dev pages (`/dev/` on the dev server) show the same split, with a filter per
release; the list is in `apps/game/src/dev/buildings.ts` (`MILESTONE_OF`). Names, sides and roles come from
`design/balance.xlsx`.
